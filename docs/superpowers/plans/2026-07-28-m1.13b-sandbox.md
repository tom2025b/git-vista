# M1.13b — the Git-process sandbox (#66)

**For agentic workers: REQUIRED SUB-SKILL: `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans`.**

## Goal

Ship the bounded, irreversible, *disclosed* Git-process sandbox the round-4 verdict settled on: a single pure `sandbox_argv(Policy)` chokepoint feeding one fused `gv-sandbox` shim (Landlock, then seccomp, then `execve` git), applied at every production spawn site, tiered so network operations still work, and proven by a 17-invariant escape battery that always tests the composed launcher.

## Architecture

Every production git spawn goes through one pure function, `sandbox::sandbox_argv(&Policy) -> Vec<OsString>`, which emits a launcher argv whose fixed reviewed prefix is either `bwrap …` (strict tier) or nothing (network tier) and whose tail is always `["--", "git"]`. That argv is executed by `sandbox::spawn::spawn_git_async` / `spawn_git_sync` — the only two places in the codebase that construct a `Command` from a non-literal program name — and terminates in `crates/git-vista-server/src/bin/gv-sandbox.rs`, a single fused binary that applies Landlock (ABI floor 6, fail-closed), then a terminal-action seccomp filter (AF_UNIX/io_uring/unshare/setns/seccomp denied), then `execve`s git without forking. Repository metadata is resolved and validated against the managed root *before* any policy is built, so a repository's own `.git` gitfile can never steer the grant set outside the catalog.

## Tech Stack

- Rust (stable), workspace crates `git-vista-core`, `git-vista-protocol`, `git-vista-git`, `git-vista-server`, `git-vista` (Leptos/wasm frontend).
- `tokio` 1.52.3 with the `process` feature (already present) — `tokio::process::Command`.
- **New direct dependencies of `git-vista-server`:** `libc = "0.2"` (raw Landlock syscalls, `prctl`, syscall numbers) and `seccompiler = "0.5"` (cBPF assembly with masked argument comparisons). No `landlock` crate — the raw-syscall path is ~120 lines, has no version risk around the ABI-6 structures, and lets the ABI floor be checked exactly.
- **New external runtime binary:** `bubblewrap` (`bwrap`), used only by the strict tier.
- Existing test conventions: `#[cfg(test)] mod <name>;` sibling files (pattern B, as `planner/{contract,coordination,lifecycle}_suite.rs` already do).

## Global Constraints

These apply to **every** task below. They are quoted requirements, not guidance.

1. **Landlock ABI floor is 6, not 3 and not 8.** From correction **C5** (verdict §9.2): *"Declare **ABI 6**, not 3 and not 8. ABI 8 contributes only `LANDLOCK_RESTRICT_SELF_TSYNC`, which this design does not need if the launcher is single-threaded — and it should be. […] **Fail closed** when the declared minimum is unavailable: silently applying a weaker best-effort policy is incompatible with any stated claim."* The shim is single-threaded by construction. `landlock_create_ruleset(NULL, 0, LANDLOCK_CREATE_RULESET_VERSION) < 6` ⇒ the shim exits non-zero with a named error, never a degraded policy.

2. **Test the composed launcher, never a primitive alone.** From verdict §9.4: *"The single methodological failure of round 4 was verifying layers in isolation and then crediting the composition. Every test below runs the **whole launcher**, in one configuration, against a real repository."* And §5: *"The composition rule is absolute: every invariant is verified in *one* configuration — the real production argv — never in a sub-layer."* Concretely, for every task in this plan: a test may **not** call `landlock_restrict_self`, install a seccomp filter, or exec `bwrap` directly. It must go through `sandbox_argv` + `spawn_git_{sync,async}` (for git behaviour) or `probe_argv` + the shim's `--self-probe` mode (for in-sandbox syscall behaviour). A test that constructs a primitive itself is a defect in the test, regardless of whether it passes.

3. **The shim is a single fused binary.** From verdict §7.1: *"The shim's own path **must** be inside a Landlock-granted RO tree, or `execve` of it is denied. I hit this: `ll: exec .../sc: Permission denied` (rc=105), and it silently made a benchmark look 3× *faster* than bare git. A single fused shim (Landlock + seccomp + exec in one binary) avoids the whole class."* `gv-sandbox` therefore does Landlock **and** seccomp **and** the exec of git in one process image. It must contain `.exec()` and must **not** contain `.spawn()`, `.output()`, or `.status()`. Task 15 makes that a source-level assertion.

4. **The argv tail is structurally asserted.** From **INV-16**: *"add a *structural* assertion that the produced argv **ends in `["--", "git", ...]` after a fixed reviewed prefix**. This is F7 and it is a reviewed sub-task, not a side effect."* `sandbox_argv` output must satisfy: either it is exactly `["git"]` (the `Unsandboxed` tier, reachable only through explicit persisted per-repo trust) or its last two elements are `"--"` and `"git"` and its prefix up to the first `"--"` equals a pinned reviewed constant. The probe argv (`probe_argv`) is a separate reviewed shape ending `["--self-probe"]` and never names a program at all.

5. **C1 — seccomp stacking is not monotonic.** *"A newer `SECCOMP_RET_USER_NOTIF` filter can override earlier `USER_NOTIF`/`TRACE` handling and continue a syscall. The composition therefore must use **higher-precedence terminal denials** for the boundary *and* **deny the hook the `seccomp` syscall itself**."* Every denial in this plan is `SECCOMP_RET_ERRNO` or `SECCOMP_RET_KILL_PROCESS` — never `TRACE`, never `USER_NOTIF` — and both `seccomp(2)` and `prctl(PR_SET_SECCOMP)` are denied to the child.

6. **C2 — register width.** *"Seccomp reports syscall registers *before* the kernel truncates arguments to their declared types. A socket-family comparison must mask to the effective low-width `int`, or `AF_UNIX | 0x1_0000_0000` compares unequal and passes."* Every argument comparison in the filter uses `SeccompCmpArgLen::Dword`.

7. **C3 — mount namespace and a fresh procfs are required.** *"A PID namespace does **not** update an inherited procfs mount: `/proc` keeps its mounter's PID view. Add a mount namespace with private propagation and either mount a fresh `/proc` for the child PID namespace or expose no `/proc` at all."* The strict tier's bwrap prefix therefore carries `--proc /proc` (bwrap always creates a mount namespace with private propagation).

8. **C4 — `/dev/shm`.** *"An IPC namespace isolates System V IPC and POSIX message queues but **not** pathname-based POSIX shared memory or named semaphores under `/dev/shm`. Provide a private `/dev/shm` or deny it in the filesystem policy."* The strict tier prefix carries `--tmpfs /dev/shm`; the network tier denies `/dev/shm` in the Landlock rule set.

9. **D5 is Option B and is not re-litigated.** Read-allow `$HOME`, write-deny `$HOME`, plus an explicit secret denylist (`~/.ssh`, `~/.claude`, `~/.config/gh`, `~/.aws`, `~/.netrc`, `~/.npmrc`, browser profile dirs). Landlock's most-specific-rule semantics make the denylist a `path_beneath` rule with `allowed_access = 0`.

10. **D4 is Option A and is not re-litigated.** Full tier everywhere **except** network operations. The read path pays the strict tier's ~7 ms until a profile says otherwise.

11. **D6 is Lane A's assumed default, NOT yet confirmed by Tom.** The plan assumes verdict §6 D6 **Option A**: *"`sudo sysctl -w kernel.apparmor_restrict_unprivileged_userns=0` as a preflight step, failing loudly if the write fails. GitHub runners have passwordless sudo."* **This assumption has not been confirmed by Tom.** It is flagged here the same way #65's scope narrowing was flagged rather than silently assumed. Task 17 carries the note into its own commit message verbatim. If Tom chooses D6 Option B (host-gated tests, no CI validation of the bwrap-dependent invariants), only Task 17 changes; every other task is unaffected because INV-13 (Task 9) makes the capability/escape distinction explicit regardless.

12. **Subagents must not write git.** A background checkpointer owns the index. No `git add`/`commit`/`push`/`checkout`/`switch`/`reset`/`rebase`/`stash`, no branch deletion, no `./dev wip` from a subagent. Read-only git and throwaway `tempfile::TempDir` fixture repos are fine. The "commit" step written into each task below is executed by the parent session or the checkpointer, not by a task subagent.

13. **Scope deviation, flagged not silent — test-helper spawn sites are NOT migrated.** Verdict §7.1's diagram routes *"~39 test-helper sites incl. `history.rs` sync helpers"* through `spawn_git_sync`. This plan migrates **one** of them (`git_cmd.rs:385 batch_child`, because it is the witness for the process-lifetime tests and must keep mirroring the real production spawn shape) and leaves the other 37 as raw `Command::new("git")`. Two reasons, both structural: (a) `git-vista-git` is a *dependency* of `git-vista-server`, so its 8 test sites in `src/history.rs` **cannot** reach the server's sandbox module without inverting the dependency graph; (b) fixture construction is not the thing under test — the escape and compat batteries call `spawn_git_sync` directly, which is what Global Constraint 2 actually requires. If a later session wants full test-helper migration it needs a `git-vista-sandbox` crate below `git-vista-git`; that is not M1.13b.

14. **Every new dependency is a reviewed decision (F10).** *"`DEPENDENCY_EXCEPTIONS.md` does not gate new crates — Confirmed."* Task 2 adds a kernel-API dependency register and a CI step, because `libc` and `seccompiler` would otherwise sail in unreviewed.

```rust
//! M1.13b (#66): the single argv chokepoint for every git process this server
//! spawns. See `docs/superpowers/specs/2026-07-28-m1.13-round4-verdict.md`.
//!
//! Everything in this file is **pure**. No syscall, no I/O, no async. That is
//! deliberate and it is what dissolved the "do the ~39 synchronous test helpers
//! have to become async?" question (verdict §7.1): because the sandbox is
//! nothing but argv, the sync and async spawn wrappers share one policy
//! function and neither needs `block_on` or a `pre_exec` closure.

use std::ffi::OsString;
use std::path::PathBuf;

#[cfg(test)]
mod argv;

/// The strict tier's outer launcher. An external binary, deliberately: it is
/// the only thing here that creates namespaces, and `--unshare-net` is what
/// makes the strict tier incompatible with `git push` (F3).
pub(crate) const BWRAP_BIN: &str = "bwrap";

/// Overrides the shim path for tests and for a packaged install where the
/// shim does not sit beside the server binary.
pub(crate) const SHIM_BIN_ENV: &str = "GIT_VISTA_SANDBOX_BIN";

/// C5: the declared minimum Landlock ABI. Six, because ABI 6 is the first
/// with the signal and abstract-unix-socket scopes this design uses; ABI 8
/// adds only `TSYNC`, which a single-threaded launcher does not need.
pub(crate) const LANDLOCK_ABI_FLOOR: u32 = 6;

/// D5 Option B: `$HOME` is read-allowed and write-denied, and *these* are the
/// paths denied outright. Relative to `$HOME`. The list is short and auditable
/// on purpose — round 4's blanket-deny-plus-allowlist shape needed three
/// iterations to make one `git commit` work (F1, F-NEW-2) and would have kept
/// growing for every credential helper and hook interpreter.
pub(crate) const DEFAULT_SECRET_DENIES: &[&str] = &[
    ".ssh",
    ".claude",
    ".config/gh",
    ".aws",
    ".netrc",
    ".npmrc",
    ".config/google-chrome",
    ".config/chromium",
    ".mozilla",
];

/// The reviewed bwrap prefix, pinned as a constant so INV-16's structural
/// assertion has something to compare against and a drift shows up as a test
/// failure rather than as a quietly weaker sandbox.
///
/// `--proc /proc` is C3 (a pid namespace does not update an inherited procfs).
/// `--tmpfs /dev/shm` is C4 (an ipc namespace does not cover pathname-based
/// POSIX shared memory). `--die-with-parent` plus `--unshare-pid` is INV-8.
pub(crate) const STRICT_BWRAP_PREFIX: &[&str] = &[
    BWRAP_BIN,
    "--bind", "/", "/",
    "--dev-bind", "/dev", "/dev",
    "--proc", "/proc",
    "--tmpfs", "/dev/shm",
    "--unshare-pid",
    "--unshare-net",
    "--unshare-ipc",
    "--unshare-uts",
    "--unshare-cgroup",
    "--die-with-parent",
    "--new-session",
];

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Tier {
    /// Landlock + seccomp inside a bwrap pid/net/ipc/uts/cgroup namespace.
    /// Everything except network operations (D4 Option A).
    Strict,
    /// Landlock + seccomp, no namespaces, `AF_INET`/`AF_INET6` permitted.
    /// The only tier in which `git push`/`fetch`/`clone` can work (F3).
    Network,
    /// No sandbox at all. Reachable only through explicit, persisted, per-repo
    /// operator trust, and it flies a permanent banner (INV-15).
    Unsandboxed,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) enum HookMode {
    /// Repository hooks run. They gate the operation normally (INV-11).
    Run,
    /// `core.hooksPath` is pointed at a server-owned empty directory, so no
    /// repository hook can run at all. The state the probe drops to when the
    /// host cannot provide the declared minimum (INV-13).
    Blocked { empty_dir: PathBuf },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct Policy {
    pub tier: Tier,
    /// Absolute path of the fused `gv-sandbox` shim.
    pub shim: PathBuf,
    pub rw_trees: Vec<PathBuf>,
    pub ro_trees: Vec<PathBuf>,
    pub secret_denies: Vec<PathBuf>,
    pub hook_mode: HookMode,
}

/// The chokepoint. Returns the complete launcher argv **up to and including
/// the program name `git`**; the caller appends `-C <repo> <args…>`.
///
/// INV-16: the result is either exactly `["git"]` (the `Unsandboxed` tier) or
/// it ends in `["--", "git"]` after a fixed reviewed prefix.
pub(crate) fn sandbox_argv(policy: &Policy) -> Vec<OsString> {
    if policy.tier == Tier::Unsandboxed {
        return vec![OsString::from("git")];
    }
    let mut argv = shim_argv(policy);
    argv.push(OsString::from("--"));
    argv.push(OsString::from("git"));
    argv
}

/// The escape battery's launcher. Identical setup, different terminal mode:
/// the shim runs its built-in checks in-process instead of exec'ing anything.
/// That is what lets the battery satisfy the composition rule — the checks run
/// behind the very same Landlock and seccomp code path production uses —
/// without ever teaching the shim to exec an arbitrary program.
pub(crate) fn probe_argv(policy: &Policy) -> Vec<OsString> {
    let mut argv = shim_argv(policy);
    argv.push(OsString::from("--self-probe"));
    argv
}

fn shim_argv(policy: &Policy) -> Vec<OsString> {
    let mut argv: Vec<OsString> = Vec::new();
    if policy.tier == Tier::Strict {
        argv.extend(STRICT_BWRAP_PREFIX.iter().map(OsString::from));
        argv.push(OsString::from("--"));
    }
    argv.push(policy.shim.clone().into_os_string());
    argv.push(OsString::from("--abi-floor"));
    argv.push(OsString::from(LANDLOCK_ABI_FLOOR.to_string()));
    for p in &policy.rw_trees {
        argv.push(OsString::from("--rw"));
        argv.push(p.clone().into_os_string());
    }
    for p in &policy.ro_trees {
        argv.push(OsString::from("--ro"));
        argv.push(p.clone().into_os_string());
    }
    for p in &policy.secret_denies {
        argv.push(OsString::from("--deny"));
        argv.push(p.clone().into_os_string());
    }
    match &policy.hook_mode {
        HookMode::Run => argv.push(OsString::from("--hooks-run")),
        HookMode::Blocked { empty_dir } => {
            argv.push(OsString::from("--hooks-blocked"));
            argv.push(empty_dir.clone().into_os_string());
        }
    }
    argv.push(OsString::from(match policy.tier {
        Tier::Strict => "--net-deny",
        Tier::Network => "--net-allow",
        Tier::Unsandboxed => unreachable!("handled by the caller"),
    }));
    argv
}
```

```rust
//! M1.13b (#66): the fused sandbox shim.
//!
//! **Fused on purpose.** Round 4 ran Landlock and seccomp as two separate
//! helper binaries and hit `exec .../sc: Permission denied` (rc=105) — the
//! second helper's own path was not inside a Landlock-granted tree — which
//! silently made a benchmark look 3x *faster* than bare git. One process image
//! that restricts itself and then `execve`s git cannot have that bug.
//!
//! Order is load-bearing and is the reverse of how it reads:
//!   1. close every inherited descriptor above 2      (INV-7)
//!   2. `prctl(PR_SET_NO_NEW_PRIVS, 1)`               (required by both layers)
//!   3. Landlock: check the ABI floor, build, restrict_self   (INV-1..3)
//!   4. seccomp: assemble terminal-action cBPF, apply (INV-4..6, C1, C2)
//!   5. `execve` git — never fork, never spawn        (fused-binary rule)
//!
//! This binary never execs anything but `git`, and its only other terminal
//! mode, `--self-probe`, execs nothing at all.

use std::ffi::OsString;
use std::path::PathBuf;

mod landlock;
mod seccomp;
mod selfprobe;

const EXIT_ARGV: i32 = 90;
const EXIT_ABI: i32 = 91;
const EXIT_LANDLOCK: i32 = 92;
const EXIT_SECCOMP: i32 = 93;
const EXIT_EXEC: i32 = 94;

#[derive(Debug)]
struct Args {
    abi_floor: u32,
    rw: Vec<PathBuf>,
    ro: Vec<PathBuf>,
    deny: Vec<PathBuf>,
    hooks_blocked_dir: Option<PathBuf>,
    net_allow: bool,
    /// `Some(args)` = exec `git <args>`; `None` = `--self-probe`.
    git_args: Option<Vec<OsString>>,
}

fn die(code: i32, msg: &str) -> ! {
    eprintln!("gv-sandbox: {msg}");
    std::process::exit(code)
}

fn parse(mut it: impl Iterator<Item = OsString>) -> Args {
    let mut a = Args {
        abi_floor: 6,
        rw: Vec::new(),
        ro: Vec::new(),
        deny: Vec::new(),
        hooks_blocked_dir: None,
        net_allow: false,
        git_args: None,
    };
    let mut saw_net = false;
    let mut saw_hooks = false;
    while let Some(arg) = it.next() {
        let s = arg.to_string_lossy().into_owned();
        let mut want = |name: &str| -> OsString {
            it.next().unwrap_or_else(|| die(EXIT_ARGV, &format!("{name} needs a value")))
        };
        match s.as_str() {
            "--abi-floor" => {
                a.abi_floor = want("--abi-floor")
                    .to_string_lossy()
                    .parse()
                    .unwrap_or_else(|_| die(EXIT_ARGV, "--abi-floor is not a number"));
            }
            "--rw" => a.rw.push(PathBuf::from(want("--rw"))),
            "--ro" => a.ro.push(PathBuf::from(want("--ro"))),
            "--deny" => a.deny.push(PathBuf::from(want("--deny"))),
            "--hooks-run" => saw_hooks = true,
            "--hooks-blocked" => {
                saw_hooks = true;
                a.hooks_blocked_dir = Some(PathBuf::from(want("--hooks-blocked")));
            }
            "--net-deny" => { saw_net = true; a.net_allow = false; }
            "--net-allow" => { saw_net = true; a.net_allow = true; }
            "--self-probe" => {
                a.git_args = None;
                return finish(a, saw_hooks, saw_net, true);
            }
            "--" => {
                let program = it.next().unwrap_or_else(|| die(EXIT_ARGV, "`--` with no program"));
                if program != OsString::from("git") {
                    die(EXIT_ARGV, "this shim execs only `git`; nothing else is reachable through it");
                }
                a.git_args = Some(it.collect());
                return finish(a, saw_hooks, saw_net, true);
            }
            other => die(EXIT_ARGV, &format!("unknown argument `{other}`")),
        }
    }
    die(EXIT_ARGV, "no terminal mode: expected `-- git …` or `--self-probe`")
}

fn finish(a: Args, saw_hooks: bool, saw_net: bool, saw_terminal: bool) -> Args {
    if !saw_hooks { die(EXIT_ARGV, "a hook mode is mandatory: --hooks-run or --hooks-blocked <dir>"); }
    if !saw_net { die(EXIT_ARGV, "a network mode is mandatory: --net-deny or --net-allow"); }
    if !saw_terminal { die(EXIT_ARGV, "no terminal mode"); }
    a
}

/// INV-7 / A7: rights on an already-open descriptor are fixed at open time and
/// survive `restrict_self`, so a descriptor the supervisor forgot to mark
/// `O_CLOEXEC` is a hole Landlock cannot close. Rust opens with `O_CLOEXEC` by
/// default, but "by default" is not an invariant — this closes them anyway, and
/// `escape::no_leaked_fd` asserts the result from inside.
fn close_inherited_descriptors() {
    let Ok(entries) = std::fs::read_dir("/proc/self/fd") else {
        // No procfs (a `--proc`-less namespace): fall back to a bounded sweep.
        for fd in 3..1024 {
            unsafe { libc::close(fd) };
        }
        return;
    };
    let fds: Vec<i32> = entries
        .filter_map(|e| e.ok())
        .filter_map(|e| e.file_name().to_string_lossy().parse::<i32>().ok())
        .filter(|fd| *fd > 2)
        .collect();
    for fd in fds {
        unsafe { libc::close(fd) };
    }
}

fn main() {
    let args = parse(std::env::args_os().skip(1));
    close_inherited_descriptors();

    if unsafe { libc::prctl(libc::PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0) } != 0 {
        die(EXIT_LANDLOCK, "PR_SET_NO_NEW_PRIVS failed");
    }

    let abi = landlock::abi_version().unwrap_or(0);
    if abi < args.abi_floor {
        die(EXIT_ABI, &format!(
            "Landlock ABI {abi} is below the declared floor {} — refusing to run with a weaker \
             policy (C5: fail closed, never best-effort)", args.abi_floor));
    }
    if let Err(e) = landlock::restrict(&args.rw, &args.ro, &args.deny) {
        die(EXIT_LANDLOCK, &format!("Landlock setup failed: {e}"));
    }
    if let Err(e) = seccomp::apply(args.net_allow) {
        die(EXIT_SECCOMP, &format!("seccomp setup failed: {e}"));
    }

    match args.git_args {
        None => selfprobe::run(),
        Some(git_args) => {
            if let Some(dir) = &args.hooks_blocked_dir {
                std::env::set_var("GIT_CONFIG_COUNT", "1");
                std::env::set_var("GIT_CONFIG_KEY_0", "core.hooksPath");
                std::env::set_var("GIT_CONFIG_VALUE_0", dir);
            }
            let err = exec_git(&git_args);
            die(EXIT_EXEC, &format!("execve git failed: {err}"));
        }
    }
}

/// The fused exec. `CommandExt::exec` replaces this process image — it does not
/// fork, does not spawn, and never returns on success. That is the whole point
/// of the fused-binary rule, and `argv_boundary` asserts textually that this
/// file contains `.exec()` and none of `.spawn()`/`.output()`/`.status()`.
fn exec_git(args: &[OsString]) -> std::io::Error {
    use std::os::unix::process::CommandExt;
    std::process::Command::new("git").args(args).exec()
}
```

**3.4 — Implement the Landlock module (6 min).** Create `crates/git-vista-server/src/bin/gv-sandbox/landlock.rs` — note the module files live in a directory named after the binary, which cargo resolves for `src/bin/gv-sandbox.rs`:

```rust
//! Raw Landlock syscalls. No wrapper crate on purpose (see
//! docs/NATIVE_DEPENDENCIES.md): the ABI-6 attribute layout and the exact
//! floor check are the security-relevant surface, and a crate that silently
//! negotiates a weaker ABI is precisely what C5 forbids.

use std::os::unix::io::AsRawFd;
use std::path::Path;

const SYS_CREATE_RULESET: libc::c_long = 444;
const SYS_ADD_RULE: libc::c_long = 445;
const SYS_RESTRICT_SELF: libc::c_long = 446;

const CREATE_RULESET_VERSION: u32 = 1 << 0;
const RULE_PATH_BENEATH: u32 = 1;

// The ABI-6 filesystem access set, bit for bit.
const FS_EXECUTE: u64 = 1 << 0;
const FS_WRITE_FILE: u64 = 1 << 1;
const FS_READ_FILE: u64 = 1 << 2;
const FS_READ_DIR: u64 = 1 << 3;
const FS_REMOVE_DIR: u64 = 1 << 4;
const FS_REMOVE_FILE: u64 = 1 << 5;
const FS_MAKE_CHAR: u64 = 1 << 6;
const FS_MAKE_DIR: u64 = 1 << 7;
const FS_MAKE_REG: u64 = 1 << 8;
const FS_MAKE_SOCK: u64 = 1 << 9;
const FS_MAKE_FIFO: u64 = 1 << 10;
const FS_MAKE_BLOCK: u64 = 1 << 11;
const FS_MAKE_SYM: u64 = 1 << 12;
const FS_REFER: u64 = 1 << 13;
const FS_TRUNCATE: u64 = 1 << 14;
const FS_IOCTL_DEV: u64 = 1 << 15;

const FS_ALL: u64 = FS_EXECUTE | FS_WRITE_FILE | FS_READ_FILE | FS_READ_DIR
    | FS_REMOVE_DIR | FS_REMOVE_FILE | FS_MAKE_CHAR | FS_MAKE_DIR | FS_MAKE_REG
    | FS_MAKE_SOCK | FS_MAKE_FIFO | FS_MAKE_BLOCK | FS_MAKE_SYM | FS_REFER
    | FS_TRUNCATE | FS_IOCTL_DEV;

/// Read-only means read, list, and execute — and nothing that mutates. D5
/// Option B's "read-allow $HOME" is exactly this set applied to `$HOME`.
const FS_RO: u64 = FS_EXECUTE | FS_READ_FILE | FS_READ_DIR;

const NET_BIND_TCP: u64 = 1 << 0;
const NET_CONNECT_TCP: u64 = 1 << 1;

/// ABI 6 scopes. `ABSTRACT_UNIX_SOCKET` is why the floor is 6 and not 3.
/// It closes abstract-namespace unix sockets at the Landlock layer; pathname
/// sockets (`/run/docker.sock`) are **not** covered until ABI 9's
/// `LANDLOCK_ACCESS_FS_RESOLVE_UNIX`, which is why seccomp is mandatory and
/// not belt-and-braces (verdict §9.1).
const SCOPE_ABSTRACT_UNIX_SOCKET: u64 = 1 << 0;
const SCOPE_SIGNAL: u64 = 1 << 1;

#[repr(C)]
struct RulesetAttr {
    handled_access_fs: u64,
    handled_access_net: u64,
    scoped: u64,
}

/// `struct landlock_path_beneath_attr` is `__attribute__((packed))` in the
/// UAPI. Getting this wrong yields EINVAL at best and a silently wrong rule at
/// worst, so the packing is not optional.
#[repr(C, packed)]
struct PathBeneathAttr {
    allowed_access: u64,
    parent_fd: i32,
}

pub fn abi_version() -> Option<u32> {
    let rc = unsafe {
        libc::syscall(SYS_CREATE_RULESET, std::ptr::null::<RulesetAttr>(), 0usize, CREATE_RULESET_VERSION)
    };
    (rc > 0).then(|| rc as u32)
}

fn add_path_rule(ruleset: i32, path: &Path, access: u64) -> std::io::Result<bool> {
    let file = match std::fs::File::open(path) {
        Ok(f) => f,
        // A path that does not exist cannot be granted or denied. Report it so
        // the caller can log it; it is never an error, because `~/.aws` not
        // existing is the common case and must not fail the launch.
        Err(_) => return Ok(false),
    };
    let attr = PathBeneathAttr { allowed_access: access, parent_fd: file.as_raw_fd() };
    let rc = unsafe {
        libc::syscall(SYS_ADD_RULE, ruleset, RULE_PATH_BENEATH, &attr as *const _, 0usize)
    };
    if rc != 0 {
        return Err(std::io::Error::last_os_error());
    }
    Ok(true)
}

/// Build and enter the ruleset. Irrevocable: after `restrict_self` there is no
/// syscall that widens it, `PR_SET_NO_NEW_PRIVS` cannot be cleared, and
/// `unshare(CLONE_NEWUSER)` to uid 0 does not escape it (F-NEW-4, measured).
///
/// Denies are added **after** grants, deliberately: Landlock evaluates the most
/// specific matching rule, so a `~/.ssh` rule with `allowed_access = 0` beats
/// the `$HOME` read grant above it. That is the whole mechanism behind D5
/// Option B.
pub fn restrict(rw: &[std::path::PathBuf], ro: &[std::path::PathBuf], deny: &[std::path::PathBuf])
    -> std::io::Result<()>
{
    let attr = RulesetAttr {
        handled_access_fs: FS_ALL,
        handled_access_net: NET_BIND_TCP | NET_CONNECT_TCP,
        scoped: SCOPE_ABSTRACT_UNIX_SOCKET | SCOPE_SIGNAL,
    };
    let ruleset = unsafe {
        libc::syscall(SYS_CREATE_RULESET, &attr as *const _, std::mem::size_of::<RulesetAttr>(), 0u32)
    };
    if ruleset < 0 {
        return Err(std::io::Error::last_os_error());
    }
    let ruleset = ruleset as i32;

    for p in rw { add_path_rule(ruleset, p, FS_ALL)?; }
    for p in ro { add_path_rule(ruleset, p, FS_RO)?; }
    for p in deny { add_path_rule(ruleset, p, 0)?; }

    let rc = unsafe { libc::syscall(SYS_RESTRICT_SELF, ruleset, 0u32) };
    unsafe { libc::close(ruleset) };
    if rc != 0 {
        return Err(std::io::Error::last_os_error());
    }
    Ok(())
}
```

```rust
//! The seccomp half of the composition.
//!
//! Two corrections from the independent spec lane are load-bearing here and
//! both fail *silently* if dropped:
//!
//! **C1 — stacking is not unconditionally monotonic.** A newer
//! `SECCOMP_RET_USER_NOTIF` filter can override earlier `USER_NOTIF`/`TRACE`
//! handling and continue a syscall. So every action below is terminal
//! (`Errno`), never `Trace` and never `Notify`, *and* the child is denied the
//! `seccomp` syscall and `prctl(PR_SET_SECCOMP)` outright.
//!
//! **C2 — register width.** Seccomp sees registers before the kernel truncates
//! arguments to their declared types, so `AF_UNIX | 0x1_0000_0000` compares
//! unequal to `AF_UNIX` under a 64-bit compare. Every comparison here is
//! `Dword`.
//!
//! **F-NEW-1 — io_uring.** `IORING_OP_SOCKET` reached `/run/docker.sock`
//! through this exact filter *and through bwrap*, first-party, on this kernel.
//! Denying the three ring syscalls closes it and costs nothing: git does not
//! use io_uring (measured — `status`, `commit`, `log` all rc=0).

use std::collections::BTreeMap;

use seccompiler::{
    SeccompAction, SeccompCmpArgLen, SeccompCmpOp, SeccompCondition, SeccompFilter, SeccompRule,
};

const PR_SET_SECCOMP: u64 = 22;

pub fn apply(net_allow: bool) -> std::io::Result<()> {
    let err = |e: seccompiler::Error| std::io::Error::other(format!("{e:?}"));
    let mut rules: BTreeMap<i64, Vec<SeccompRule>> = BTreeMap::new();

    // Unconditional terminal denials. An empty rule vector means "this syscall
    // always takes the match action".
    for nr in [
        libc::SYS_io_uring_setup,
        libc::SYS_io_uring_enter,
        libc::SYS_io_uring_register,
        libc::SYS_unshare,
        libc::SYS_setns,
        libc::SYS_seccomp,
        libc::SYS_socketpair,
        libc::SYS_mount,
        libc::SYS_pivot_root,
        libc::SYS_ptrace,
        libc::SYS_process_vm_readv,
        libc::SYS_process_vm_writev,
        libc::SYS_add_key,
        libc::SYS_keyctl,
        libc::SYS_request_key,
        libc::SYS_bpf,
        libc::SYS_perf_event_open,
        libc::SYS_userfaultfd,
        libc::SYS_open_by_handle_at,
    ] {
        rules.insert(nr, Vec::new());
    }

    // C1's second half: `prctl(PR_SET_SECCOMP, …)` is the other way to install
    // a filter, and it must be shut with the same terminal action.
    rules.insert(
        libc::SYS_prctl,
        vec![SeccompRule::new(vec![SeccompCondition::new(
            0,
            SeccompCmpArgLen::Dword,
            SeccompCmpOp::Eq,
            PR_SET_SECCOMP,
        )
        .map_err(err)?])
        .map_err(err)?],
    );

    // `socket(2)`: a default-deny allowlist over the family argument, not a
    // denylist (verdict §9.1 — "Move to default-deny allowlist. Omissions then
    // become visible compatibility failures instead of silent bypasses").
    // Strict tier: no family at all. Network tier: AF_INET/AF_INET6 only, so
    // AF_UNIX, AF_NETLINK, AF_PACKET and anything future are all denied.
    let socket_rules = if net_allow {
        vec![SeccompRule::new(vec![
            SeccompCondition::new(0, SeccompCmpArgLen::Dword, SeccompCmpOp::Ne, libc::AF_INET as u64)
                .map_err(err)?,
            SeccompCondition::new(0, SeccompCmpArgLen::Dword, SeccompCmpOp::Ne, libc::AF_INET6 as u64)
                .map_err(err)?,
        ])
        .map_err(err)?]
    } else {
        Vec::new()
    };
    rules.insert(libc::SYS_socket, socket_rules);

    let filter = SeccompFilter::new(
        rules,
        // Everything not named above runs. The boundary here is a *reduction*
        // of authority, not an allowlist of git's syscalls: a full allowlist
        // would break on the next git or glibc version and fail closed in a way
        // that reads as a Git-Vista bug.
        SeccompAction::Allow,
        SeccompAction::Errno(libc::EACCES as u32),
        std::env::consts::ARCH.try_into().map_err(err)?,
    )
    .map_err(err)?;

    let program: seccompiler::BpfProgram = filter.try_into().map_err(err)?;
    seccompiler::apply_filter(&program).map_err(err)?;
    Ok(())
}
```

**4.4 — Implement `--self-probe` (7 min).** Replace `crates/git-vista-server/src/bin/gv-sandbox/selfprobe.rs`:

```rust
//! The in-sandbox truth table.
//!
//! This runs **after** `restrict()` and `apply()`, in the same process, so
//! every answer it gives is an answer about the composed launcher — never
//! about a primitive in isolation. That is the round-4 methodological failure
//! this mode exists to make impossible.
//!
//! It execs nothing. `probe_argv` never names a program, so "the shim can only
//! ever exec git" stays literally true.

use std::io::Write;
use std::path::Path;

fn errno_name() -> String {
    match std::io::Error::last_os_error().raw_os_error() {
        Some(libc::EACCES) => "EACCES".into(),
        Some(libc::EPERM) => "EPERM".into(),
        Some(libc::ENOSYS) => "ENOSYS".into(),
        Some(other) => format!("ERRNO_{other}"),
        None => "OK".into(),
    }
}

fn try_socket(domain: libc::c_int) -> String {
    let fd = unsafe { libc::socket(domain, libc::SOCK_STREAM, 0) };
    if fd >= 0 {
        unsafe { libc::close(fd) };
        return "OK".into();
    }
    errno_name()
}

/// C2's falsifying probe: the same family with a high bit set. A filter that
/// compares the full 64-bit register lets this through.
fn try_socket_high_bits() -> String {
    let domain = (libc::AF_UNIX as i64 | 0x1_0000_0000) as libc::c_int;
    try_socket(domain)
}

fn try_socketpair() -> String {
    let mut fds = [0i32; 2];
    if unsafe { libc::socketpair(libc::AF_UNIX, libc::SOCK_STREAM, 0, fds.as_mut_ptr()) } == 0 {
        unsafe { libc::close(fds[0]); libc::close(fds[1]) };
        return "OK".into();
    }
    errno_name()
}

fn try_io_uring() -> String {
    // Raw, because the point is the syscall, not a crate's wrapper.
    let mut params = [0u8; 120];
    let rc = unsafe { libc::syscall(libc::SYS_io_uring_setup, 8u32, params.as_mut_ptr()) };
    if rc >= 0 {
        unsafe { libc::close(rc as i32) };
        return "OK".into();
    }
    errno_name()
}

fn try_unshare_user() -> String {
    if unsafe { libc::unshare(libc::CLONE_NEWUSER) } == 0 { "OK".into() } else { errno_name() }
}

fn try_setns() -> String {
    let Ok(f) = std::fs::File::open("/proc/self/ns/user") else { return "NO_PROCFS".into() };
    use std::os::unix::io::AsRawFd;
    if unsafe { libc::setns(f.as_raw_fd(), 0) } == 0 { "OK".into() } else { errno_name() }
}

fn try_install_seccomp() -> String {
    // C1: an empty program is enough — the question is whether the syscall is
    // reachable at all, not whether a useful filter can be built.
    let rc = unsafe { libc::syscall(libc::SYS_seccomp, 1u32 /* SET_MODE_STRICT */, 0u32, std::ptr::null::<u8>()) };
    if rc == 0 { "OK".into() } else { errno_name() }
}

fn try_write(path: &Path) -> String {
    match std::fs::write(path, b"gv-probe") {
        Ok(()) => { let _ = std::fs::remove_file(path); "OK".into() }
        Err(e) => match e.raw_os_error() {
            Some(libc::EACCES) => "EACCES".into(),
            Some(libc::EPERM) => "EPERM".into(),
            Some(other) => format!("ERRNO_{other}"),
            None => "ERR".into(),
        },
    }
}

fn try_read(path: &Path) -> String {
    match std::fs::read(path) {
        Ok(_) => "OK".into(),
        Err(e) => match e.raw_os_error() {
            Some(libc::EACCES) => "EACCES".into(),
            Some(libc::ENOENT) => "ENOENT".into(),
            Some(other) => format!("ERRNO_{other}"),
            None => "ERR".into(),
        },
    }
}

/// A8 / C3: with a fresh procfs in a pid namespace the highest visible pid is
/// small. With an inherited procfs it is the host's, which is the bug C3 names.
fn highest_visible_pid() -> i32 {
    let Ok(entries) = std::fs::read_dir("/proc") else { return -1 };
    entries
        .filter_map(|e| e.ok())
        .filter_map(|e| e.file_name().to_string_lossy().parse::<i32>().ok())
        .max()
        .unwrap_or(-1)
}

fn open_fds() -> Vec<i32> {
    let Ok(entries) = std::fs::read_dir("/proc/self/fd") else { return vec![] };
    let mut v: Vec<i32> = entries
        .filter_map(|e| e.ok())
        .filter_map(|e| e.file_name().to_string_lossy().parse::<i32>().ok())
        .collect();
    // The directory handle this very enumeration holds is not an inherited
    // descriptor; drop the highest entry only if it is the one we opened.
    v.sort_unstable();
    v.retain(|fd| *fd <= 2);
    v
}

/// INV-12 / F6: what a hook's PATH lookup would actually resolve to, from
/// inside. The supervisor compares against its own resolution.
fn interpreters() -> Vec<(String, Option<String>)> {
    ["sh", "python3", "node"]
        .iter()
        .map(|name| {
            let found = std::env::var_os("PATH")
                .into_iter()
                .flat_map(|p| std::env::split_paths(&p).collect::<Vec<_>>())
                .map(|dir| dir.join(name))
                .find(|c| c.is_file())
                .and_then(|c| std::fs::canonicalize(c).ok())
                .map(|c| c.display().to_string());
            (name.to_string(), found)
        })
        .collect()
}

pub fn run() -> ! {
    let home = std::env::var("HOME").unwrap_or_else(|_| "/home/nobody".into());
    let secrets: Vec<(String, String)> = [".ssh", ".claude", ".config/gh", ".aws", ".netrc", ".npmrc"]
        .iter()
        .map(|rel| {
            let p = Path::new(&home).join(rel);
            let probe = if p.is_dir() { p.join("gv-probe-nonexistent") } else { p.clone() };
            (rel.to_string(), try_read(&probe))
        })
        .collect();

    let report = serde_json::json!({
        "landlock_abi": crate::landlock::abi_version().unwrap_or(0),
        "seccomp_available": true,
        "userns_available": Path::new("/proc/self/ns/user").exists(),
        "af_unix_socket": try_socket(libc::AF_UNIX),
        "af_unix_socketpair": try_socketpair(),
        "af_unix_high_bits": try_socket_high_bits(),
        "af_inet_socket": try_socket(libc::AF_INET),
        "io_uring_setup": try_io_uring(),
        "unshare_user": try_unshare_user(),
        "setns": try_setns(),
        "install_seccomp": try_install_seccomp(),
        "open_fds": open_fds(),
        "proc_pid_max": highest_visible_pid(),
        "dev_shm_write": try_write(Path::new("/dev/shm/gv-probe")),
        "secret_reads": secrets,
        "home_write": try_write(&Path::new(&home).join("GV_PWNED")),
        // INV-17 / F-NEW-3: asserted to SUCCEED. Landlock ABI 8 does not
        // mediate chmod, and a future session must not quietly assume it does.
        "chmod_outside": {
            let p = Path::new(&home).join(".gitconfig");
            if p.exists() {
                let mode = std::fs::metadata(&p).map(|m| std::os::unix::fs::PermissionsExt::mode(&m.permissions())).unwrap_or(0);
                let rc = unsafe { libc::chmod(std::ffi::CString::new(p.to_string_lossy().as_bytes()).unwrap().as_ptr(), mode) };
                if rc == 0 { "OK".to_string() } else { errno_name() }
            } else { "ENOENT".to_string() }
        },
        "interpreters": interpreters(),
    });

    let mut out = std::io::stdout();
    let _ = out.write_all(report.to_string().as_bytes());
    let _ = out.flush();
    std::process::exit(0)
}
```

> **Note on the `chmod` probe.** It re-applies the file's *existing* mode, so it proves the syscall is unmediated without changing anything. The round-4 verdict's own `chmod 777` accident (§1) is exactly why this probe is idempotent by construction.
